# Fold has a new home

**[Smithright/fold](https://github.com/Smithright/fold)** is the canonical source and public GitHub template repository.

- [Open the live demo](https://smithright.github.io/fold/)
- [Use the template](https://github.com/Smithright/fold/generate)
- [Read the authoring guide](https://github.com/Smithright/fold/blob/main/AUTHORING.md)
- [Report an issue](https://github.com/Smithright/fold/issues)

Fold’s implementation and history have moved intact. This folder keeps the original entry point discoverable. Its hosted URL redirects to the new demo and preserves the slide fragment and query string. Browser drafts remain local; download any important work before clearing browser storage.
